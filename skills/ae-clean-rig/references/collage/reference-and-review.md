# Reference Analysis and Review

## Analyze the Reference Before Building

Inspect motion as motion whenever playback is available. Study the opening, each substantial camera move, transitions, readable holds, and the ending. Use selected frames to measure layout and edge details, but do not claim that still sampling establishes smooth motion. Record whether the evidence came from playback, selected frames, tutorial captions, source compositions, or inferred construction.

Break the reference into observable events and dependencies. Determine which object arrives first, what the camera reveals, when text becomes readable, how the palette changes, and which small elements continue moving during holds. Measure the relationship between large action and secondary detail instead of relying on a general style label.

Preserve a compact detail record while working. Include paper silhouette, edge defects, annotation shape, tape angle, clips, contact shadows, optical highlights, grain density, small particles, entrance directions, and depth separation when they are visible. Each meaningful detail should remain in the construction or be identified as an intentional omission. Adding random decoration is not a substitute for preserving the reference's specific details.

When a tutorial link is part of the request, inspect its relevant material before adopting the technique. Extract the camera hierarchy, layer relationships, effect setup, and velocity design; adapt them to the new artwork. Do not transplant tutorial coordinates, paid-plugin requirements, or subject matter without checking whether they apply. State when only captions or selected sections were inspected.

## Verification and Review

Honor the requested review mode. When the user asks for preview in After Effects, do not enqueue an export, run a background renderer, upload frames, or deliver an MP4 without a new request. This also excludes saveFrameToPng and frame-audit tools that export a still; use the composition viewport instead. Use responsive preview resolution for timing, then full resolution for edges, print, and text. Saving the editable project is separate from exporting a movie.

Check the first seconds at playback speed before declaring the opening effective. Review principal entrances, camera transitions, type-on, palette changes, secondary activity, and an otherwise stationary hold. A still cannot establish smooth motion, continuous grain, or absence of flicker. If playback cannot be observed, state that limitation and leave the composition ready for the user's review.

Inspect adjacent frames around every hard cut and suspicious flash. Ensure required backgrounds, cameras, adjustment layers, and textures cover the entire master interval. Compare source duration, layer start time, and out point at the actual frame rate, including fractional rates. Tiny duration differences can produce a blank final displayed frame even when decimal values appear equal. Extend the necessary source and dependent coverage deliberately rather than masking the problem with unrelated footage.

Check expressions and evaluated numeric values on the affected motion properties, not only whether the script completed. Verify projected text bounds, visible object silhouettes, attached groups, matte alignment, and backdrop coverage at camera extremes and intermediate poses. Do not report a populated source rectangle as proof that the visible rim, lettering, or diagram is safely framed.

Test the editable surface appropriate to the deliverable on a duplicate. A prompt should tolerate a longer sentence, a replaceable photograph should tolerate a different source size, and a material control should vary without losing coverage. Check only the relevant branches for a local change; broad construction warrants broader review. Restore requested content after testing.

Save the actual edited project and read back its path. Report the exact target composition and any unresolved dependency, missing asset, expression failure, framing defect, or unobserved playback. Do not equate successful scripting with user approval or reference-perfect motion.

## Handoff and Evidence

Leave the intended composition active and ready for review. When project packaging is requested, include the editable project, collected authorized media, required dependencies, and a preserved baseline. Do not include private credentials or imply that fonts and third-party footage can always be redistributed.

Distinguish native vector construction from photographic raster assets, and disclose generated substitutes where relevant. Do not describe the whole result as generation-free or entirely vector if that is not true. Do not create additional aspect ratios, publicly share the conversation, or install optional plugins without a current request.

The technical starting values in this skill were recovered from authored native workflows used with After Effects 26.3 on macOS. They support construction decisions, not universal compatibility or a guarantee of aesthetic acceptance. Recheck installed property types, connector schemas, media, and playback when the environment or reference changes. With live application access, the completion standard is a saved, editable, technically checked composition with an honest account of what was actually reviewed. Without that access, deliver the reviewed construction script and necessary execution instructions as preparation complete, with application and verification explicitly pending; do not claim that an After Effects project was created or tested.
